# Engineering documentation gate

Inspect repository reality → installed/requested version → resolve official/high-reputation Context7 ID → atomic documentation query → implementation → tests → review.

Use for external SDK/API syntax, library configuration, migrations, version behavior, CLI commands and package debugging. Never use for ECHO business logic, Founder decisions, authorization or runtime routing.

Record verified IDs for dependencies actually used in registry.json. Docs are guidance, not authority; reconcile version conflicts against installed package metadata and official sources. Never send secrets, .env content, customer data or proprietary raw context.
