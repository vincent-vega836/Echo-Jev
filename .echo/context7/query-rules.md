# Query rules

1. Identify dependency and exact installed/requested version.
2. Resolve a reputable library ID before querying.
3. Ask one specific technical question; include version, omit repository state.
4. Send no credentials, tokens, customer data or sensitive code.
5. Record ID, version, query purpose and source; do not invent dependencies.
6. Confirm mismatched documentation against package metadata. Keep Context7 out of production observation calls.
